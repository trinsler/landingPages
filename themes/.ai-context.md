# AI Context - Theme System

## Purpose
Centralized theme system providing consistent design tokens across all apps.

## Available Themes

### 🌌 Cyber (`cyber.css`)
- **Use case**: Tech/gaming projects, futuristic designs
- **Colors**: Dark backgrounds, blue/cyan/purple accents
- **Typography**: Space Grotesk + Inter
- **Effects**: Glow effects, neon borders, matrix backgrounds
- **Classes**: `.cyber-card`, `.neon-text`, `.gradient-text-neon`

### ✨ Minimal (`minimal.css`)
- **Use case**: Business, finance, clean professional designs
- **Colors**: Light/white backgrounds, subtle grays
- **Typography**: Inter only
- **Effects**: Subtle shadows, clean lines
- **Classes**: `.minimal-card`, `.minimal-button`

### 🔮 Glass (`glass.css`)
- **Use case**: Modern, premium, transparent effects
- **Colors**: Semi-transparent backgrounds
- **Effects**: Backdrop blur, glass morphism
- **Classes**: `.glass-card`

## CSS Variable System
All themes provide standard shadcn/ui variables:

```css
:root {
  /* Core colors */
  --background: <hsl-values>;
  --foreground: <hsl-values>;
  --primary: <hsl-values>;
  --secondary: <hsl-values>;
  --muted: <hsl-values>;
  --accent: <hsl-values>;

  /* Component colors */
  --card: <hsl-values>;
  --border: <hsl-values>;
  --input: <hsl-values>;
  --ring: <hsl-values>;

  /* Utility */
  --radius: <value>;
}
```

## Usage in Apps
```css
/* In app's main.css */
@import '../../../../themes/[theme-name].css';
@import 'tailwindcss';
```

## Utility Classes
All themes provide standard utilities:
- `.bg-background`, `.bg-card`, `.bg-primary`
- `.text-foreground`, `.text-muted-foreground`
- `.border-border`

## Theme Switching
```bash
# Switch themes for testing
pnpm theme:switch <app> <theme>
pnpm theme:switch trinsler glass
pnpm theme:switch coin-boilerplate-app cyber

# Quick shortcuts
pnpm theme:cyber    # trinsler → cyber
pnpm theme:minimal  # coin-boilerplate-app → minimal
```

## When Creating New Themes
1. Copy existing theme as base
2. Update CSS variables in `:root`
3. Add theme-specific utility classes
4. Include fonts if needed
5. Test with both apps
6. Update theme switching script

## Component Compatibility
- All components use CSS variables
- No hardcoded colors
- Theme-agnostic design
- Automatic adaptation

## AI Development Notes
- Always use CSS variables, never hardcode colors
- Components work with any theme automatically
- Test theme switches during development
- Consider theme when choosing component variants
