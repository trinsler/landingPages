# AI Context - Trinsler App

## App Purpose
Landing page for Trinsler growth services with cyber/matrix theme aesthetic.

## Current Structure
```
components/
├── layout/     # AppLogo, AppNavbar, AppFooter
├── sections/   # Hero, Services, Stats, Testimonials, CTA, IntelligenceArticle
├── forms/      # NewsletterSubscription
└── ui/         # (empty - uses shared UI)
```

## Key Patterns
- Uses cyber theme (`themes/cyber.css`)
- Components use cyber-specific classes: `.cyber-card`, `.neon-text`, `.gradient-text-neon`
- Color variables: `--accent-neon`, `--accent-purple`, `--cyber-glow`
- Typography: Space Grotesk for headings, Inter for body
- Animations: Matrix-style effects, data streams, glitch effects

## Common Classes
- `.matrix-bg` - Dark matrix background
- `.cyber-card` - Cards with glow effects
- `.neon-card` - Neon border cards
- `.btn-primary` - Primary buttons with glow
- `.text-glow-blue/cyan/purple` - Text with glow effects

## Page Types
- Service-focused (B2B growth services)
- Tech/startup aesthetic
- German market (some German text)
- Professional but edgy

## When Creating Components
1. Use cyber theme classes
2. Include animations (animate-slide-up, animate-glow-pulse)
3. Follow existing component structure
4. Import from correct paths
5. Add TypeScript types if needed
