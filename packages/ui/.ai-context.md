# AI Context - UI Package

## Package Purpose
Shared UI components and utilities for all monorepo apps.

## Current Structure
```
src/
├── components/     # 24+ shared Vue components
├── composables/    # useToast, useStorage, etc.
├── icons/         # Custom SVG icons
├── index.ts       # Main exports
└── style.css      # Component styles
```

## Key Components
- **BaseCard** - Flexible card component with variants
- **Section** - Layout sections with background options
- **TerminalWindow** - Cyber-themed terminal UI
- **TagBadge** - Styled badges/tags
- **LoadingSpinner** - Loading states
- **ToastContainer** - Notification system
- **CaseStudyCard** - Project showcase
- **ArticleCard** - Blog/article display

## Theme System Integration
- Components use CSS variables from themes
- Theme-agnostic design (works with any theme)
- Shadcn/ui variable compatibility
- No hardcoded colors

## Export Patterns
```typescript
// Main exports (components + composables)
export * from './components'
export * from './composables'

// Components auto-imported in apps
import { BaseCard, Section } from '@monorepo/ui'
```

## Styling Approach
- CSS variables for theming: `hsl(var(--primary))`
- Tailwind utility classes
- Responsive design first
- Accessibility considerations

## TypeScript Usage
- Full type safety
- Props interfaces defined
- Event typing
- Generic components where appropriate

## When Creating Components
1. Use theme CSS variables only
2. Make components theme-agnostic
3. Include proper TypeScript types
4. Add responsive classes
5. Consider accessibility (ARIA, keyboard nav)
6. Export from main index.ts
7. Document props and events

## Dependencies
- Vue 3 Composition API
- Uses shared package for types
- Peer dependency on Vue

## Testing
- Component tests with Vitest
- Accessibility testing
- Cross-theme compatibility
